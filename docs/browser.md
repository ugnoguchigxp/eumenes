# ブラウザ（Braveのタブの接続・操作・撮影）

利用者が普段使うBraveのタブに接続し、開いているタブやEumenesの画面を読み取って操作し、画像として保存する。新しいブラウザやプロファイルは起動しない。設計は[設計書](../spec/browser-tabs-toolchain-design-2026-10-18.md)。現在の実装範囲は設計書の S1（接続とローカル撮影）と S2（ページ操作）、[実行Script・進捗UIと接続承認省略](../spec/browser-script-progress-ui-design-2026-10-20.md)。[固定試験と実機の未確認事項](../spec/verification/browser-script-progress-2026-10-20/README.md)は別に記録する。

| 状態 | 内容 |
| --- | --- |
| 実装済み・固定試験済み | 設定、接続、タブ一覧、撮影（表示範囲・ページ全体）、WebPへの変換とローカル保存、画面「ブラウザ」、会話の `browser_capture`。ページ操作（観測しながら一手ずつ操作する単発型の実行、確定操作の承認と続きの依頼、ページ由来の値の承認、保護のため停止したタブ、古い観測の畳込み）、会話の `browser_operate`。操作の途中の要素だけの撮影。実行Scriptの公開・進捗・履歴、補助タブ、独立したブラウザ設定セクション、暗号化したBridgeトークンによる接続の承認省略経路 |
| 未実装 | LARMへの保存（S3） |
| 未実施 | 実機のBrave・拡張機能での受入（接続→Eumenesのタブの撮影→Eumenesのリンクから開いたタブの操作と撮影）、実LLMの操作判断 |

## 準備

### 1. Playwright MCP Bridge をBraveに入れる

Chrome ウェブストアの拡張機能 **Playwright MCP Bridge**（拡張ID `mmlmfjhmonkocbjadbfplnigmagldckm`）を、Brave に追加する。BraveはChromeウェブストアの拡張機能をそのまま入れられる。入れるのは利用者で、Eumenesは拡張機能を自作・自動導入しない。

手動接続では、Braveの接続ページで対象タブを選び、操作を許可する。承認省略を有効にした場合は、保存したBridgeトークンを公式の接続機構へ渡す。接続用ページ自体が開かなくなる保証や、すべてのタブを操作できる保証はない。実際の接続対象は実機受入で確認する。

### 2. Braveの実行ファイルのパスを保存する

「設定」→「ブラウザ」、またはブラウザアーティファクト上部の「設定」を開き、Braveの実行ファイルの絶対パスを入れて保存する。環境変数は使わない。パスはSQLiteに保存される。

macOS の例:

```text
/Applications/Brave Browser.app/Contents/MacOS/Brave Browser
```

APIで確認・保存することもできる（認証付き）。空文字で保存すると設定を消す。

```text
GET /api/browser/tasks?conversationId=… → 現在の会話の直近20件（認証済みowner内）
GET /api/browser/setting          → { "executablePath": "…" | null, "suggestedPath": "…" | null, "canBrowse": true | false }
POST /api/browser/setting/browse  → { "path": "…" | null }   （ファイル選択。保存はしない。取消はnull）
PUT /api/browser/setting          { "executablePath": "/絶対パス" }
```

パスが未設定の間は、画面に「Braveの実行ファイルのパスが設定されていません」と出て、接続も撮影もできない。標準の場所（macOSの `/Applications`・`~/Applications`、Linuxの `/usr/bin/brave-browser` など）にBraveがあれば、入力欄にそのパスが入り「Braveが見つかりました」と出るので、「保存」を押せば使える。見つかったパスは保存するまで使わない（`GET /api/browser/setting` の `suggestedPath`）。

macOSでは「参照…」でファイル選択の画面が開く（backendと同じMacの画面に出る）。`Brave Browser.app` を選ぶと実行ファイルのパスが入力欄に入るので、「保存」を押す。macOS以外では「参照…」は出ず、パスを入力する。

## 接続時の承認を省略する

「設定」→「ブラウザ」の「拡張機能と接続の承認」で、Bridgeの接続トークンを入力し、「接続時の手動承認を省略」を有効にして保存する。トークンはチャットに貼らない。設定は既存の秘密設定用キーで暗号化され、画面とAPIには登録有無・有効状態・改訂番号だけを返す。変更・無効化・削除すると古い接続は使えなくなる。キーを失った場合は新しいキーで上書きせず、既存の秘密設定の復旧手順に従う。

承認省略が有効なら、新しいチャット依頼を未接続でも受け付け、担当がScriptを公開してから接続する。切断や再起動前の操作を自動で再開する機能ではない。送信・購入・公開・削除・保存等の承認と入力値の制約は維持する。

## 接続する

1. 画面「ブラウザ」の「接続・タブ」で「ブラウザに接続」を押す。会話で「ブラウザに接続して」と頼んでもよい。
2. Braveに接続ページが開く。**Eumenesのタブを選んで許可する**（通常はこのタブ）。接続は最大2分待つ。過ぎたら「接続が時間内に完了しませんでした」となり、もう一度接続する。
3. 接続中は、選んだタブ、そのタブや接続中のタブから開いたタブ、画面の「新しく開く」で開いたタブをEumenesが扱える。
4. 接続は、「切断」、Braveの終了、接続の部品の終了、backendの停止で終わる。終わったときは自動で接続し直さない。実行中の撮影は失敗として終わる。

**接続前から開いていた他のタブは見えず、操作もできない。** 撮りたい既存のタブがあれば、そのタブで接続し直す。

## 依頼と進捗を見る

ASR・テキストとも既存のチャット欄で依頼する。実際の処理に合わせて、次の行動の検討中・接続中・ページ確認中・操作中・撮影結果の保存中を表示する。ブラウザアーティファクトの初期表示は「操作」で、これから行う実行Script、実行中の手順、到達条件、結果、履歴、中止を表示する。入力欄やマイクは置かない。手順はLLMが状況に応じて決め、操作前に保存する。完了には最新の観測参照が必要で、クリック成功やtask終了だけで全手順を完了にしない。

「接続・タブ」で接続状態とタブ操作、「撮影画像」で依頼した撮影画像を確認する。ライブ映像風の静止画プレビューは追加していない。

## 撮影する

会話: 「今のタブを撮って」「ページ全体を画像にして」。担当は snapshot のタブ一覧からタブを選び、表示範囲（viewport）かページ全体（full-page）で撮影を受け付ける。受付と完了は別で、完了すると会話に「ブラウザの画像を保存しました」と出る。状況の確認と取消も会話で頼める。画面の撮影一覧からも取り消せる。

- 画像は**品質75固定の非可逆WebP**。品質・形式・ファイル名は入力できない。
- 各辺が**2,500pxを超える範囲は撮影前に拒否**する（`capture_dimensions_exceeded`）。自動で縮小・分割しない。
- 撮影は同時に3件まで。2分で時間切れになる。
- 保存先は、データベースと同じディレクトリの `browser/captures/`（既定では `data/browser/captures/`）。ファイル名は撮影IDだけから作り、ページのタイトルやURLを使わない。
- 画面で一覧・プレビュー・ダウンロードができる（`GET /api/browser/captures/:id/content`）。LARMへの保存は未対応で、画面にもそう表示する。

## 操作する

会話: 「このタブで商品名を検索して」「この画面の設定を開いて」「このURLを開いて中を見て」。担当（`browser_operate`）は依頼を `browser.task.start` で受け付け、完了は後で会話に通知される。受け付けた後は、実行担当が1ジョブ1推論で進める。観測（要素の `[ref=eN]` 付きの表示、32 KiB・深さ12・200件まで）を読み、ツールを一つずつ選び、結果を読んで次を決める。推論は最大12回で、最後の1回は結果か質問のために残す。

できること: タブの一覧・選択・新規・閉じる、URLを開く、戻る、観測、クリック、ホバー、文字入力、選択肢の選択、キー入力、待機、撮影（表示範囲・ページ全体・観測した一要素）。ツールは観測した要素だけを対象にでき、古くなった観測の `ref` は使えない。新しい観測を受け取ると、それより前の観測の本文は「失効済み」の一行（場所とタイトルだけ）に置き換わり、推論に渡る量を抑える。

### 確定操作は承認が要る

送信・購入・公開・削除・保存にあたる操作は、利用者の承認なしには実行されない。ホストが、クリックやキー入力の直前に対象要素のHTML上の意味を調べる。GET以外のフォームを送信する操作（POSTなど）、またはモデルが `effect: "commit"` と申告した操作は承認が要る。検索（GETフォーム）、リンク、フォーム外の通常のボタンは承認なしで実行する。JavaScriptだけで送信するボタンはホストが検出できないため、モデルの申告に頼る。

1. 承認が要る操作に当たると、実行せずにtaskが `needs_input` で止まり、**何をするか**（ページのオリジン、要素、操作）が会話に出る。入力して送信する操作では、入力する値も示す。
2. 会話の担当は、利用者が示された内容のとおりにはっきり同意したときだけ、`browser.task.start` に `continueFrom`（止まったtaskのID）と `approvePending: true` を付けて続きを頼む。同意していない、迷う、内容が変わったときは、付けずに新しく頼む。
3. 続きのtaskだけが承認を受け取る。同じ会話の、10分以内に止まったtaskのものに限る。承認は対象のタブ・ページ・操作・要素（と入力値）に結び付き、**一度使うと消え**、10分で失効する。操作を変えて使い回すことはできない。

### ページ由来の値は承認が要る

フォームへ入力できる値は、利用者の依頼文から取り出したものだけ。モデルは値と一緒に、依頼文の中の出所（`quote`）を示す。出所が依頼文に無い値、およびページに表示されていた文字（8文字以上の連続が、観測に現れ依頼文に無いもの）を含む値は、入力せずにtaskが止まり、その値が会話に示される。同意すると、続きのtaskでその値を使える（値そのものはモデルへは渡さず、参照だけを渡す）。

### 保護のため停止したタブ

遷移先やタブのURLが開けないアドレス（ローカル・社内、`/api/`、httpとhttps以外、名前を解決できないもの）になったタブは、画面で「保護のため停止」と表示され、切り替え・閉じる・操作・撮影ができない。Eumenesからは扱えないので、Braveで閉じるか別のページへ移し、必要なら接続し直す。操作中に開けない先へ進んだときは、モデルへ拒否として返り、別の方法を選べる。実行したか確認できない操作（`operation_indeterminate`）は自動で繰り返さず、taskを止める。

## 画面と API

| 操作 | 経路 |
| --- | --- |
| 接続・切断・タブの切替・タブを閉じる・URLを開く・撮影の取消 | 共通の `POST /api/toolchain-actions`（受付と実行が一つの transaction） |
| Braveのパスの保存 | `PUT /api/browser/setting` |
| 接続・タブ・撮影の読取り | 画面のsource（`query:browser.workspace@1`）、`GET /api/browser/connection`、`GET /api/browser/tabs`、`GET /api/browser/captures` |

Braveとの通信（接続・タブの切替など）は書込み transaction の中では行わず、受け付けた transaction と同時に queue へ積まれて、commit 後に実行される。積まれてから60秒以内に実行されなかった操作は破棄する。

## 範囲と安全

- 会話の担当に公開する操作は、接続、撮影・ページ操作の開始・状況・取消、画面を開く、だけ。クリック・入力・遷移は実行担当がホストの検査を通して行い、スクリプトの実行・Cookie や保存データの読取りはどこにも公開しない。
- 画面の「新しく開く」は http / https のURLだけを受け付け、`chrome:`・`file:`・`javascript:`・`data:` などは拒否する。ローカルや社内のアドレスは、Eumenes自身の画面のオリジン以外は開けず、そのオリジンでも `/api/` 配下は開けない。
- MCPの子プロセスには `PATH`・`HOME`・`PLAYWRIGHT_MCP_EXECUTABLE_PATH` だけを渡し、backendのtoken・LARM設定は渡さない。`@playwright/mcp` は固定版（`package.json`）をインストール済みのものから起動し、実行時に取得しない。
- MCPが書き出すスナップショットや撮影は データベースと同じディレクトリの `browser/mcp/` に置かれるが、呼出しのたびに読んだ後で空にする。起動時にも空にする。
- **プライバシー**: 接続したタブに表示されている内容（ログイン後のページを含む）が、撮影画像としてこの端末の `browser/captures/` に保存される。画像は外部へ送らない。会話の担当（LLM）が見るのは、タブのタイトルと、クエリ・フラグメントを除いた場所（`https://host/path`）、止まったtaskの案内文だけで、ページの本文は渡さない。ページ操作を実行する担当（LLM）には、操作に必要な範囲でページの観測（アクセシビリティ表示の本文）が渡る。観測はメモリと実行中のtaskの状態にだけ置き、古いものは一行に畳み、taskが終わると捨てる。終わったtaskに残るのは回数と引用したrefだけ。撮影した画像そのものはLLMに渡さない。
- **入力値と承認の保存**: 入力に使う値はtaskの間だけ保持し、taskの終了で消す。承認待ちの値は、利用者が答えるか10分で失効するまでだけ保存する。終わったtask・操作・承認・入力の記録は7日で削除する。
- 通常ログには撮影ID・段階・安全なコード・容量だけを出す。ページ本文、画像、URLの秘密を含む値は出さない（[ログ](logging.md)）。

## 障害のとき

| 症状 | 見る所 |
| --- | --- |
| 「現在は使えません」と出る | 理由の文言。未設定ならパスを保存する。「接続されていません」なら接続する |
| 接続ページが開かない | Playwright MCP Bridge が入っているか、パスがBraveの実行ファイルか |
| 接続が時間切れになる | Braveの接続ページでタブを選んで許可したか。もう一度接続する |
| 撮影が `tab_lost` | 対象のタブが閉じられたか、接続前のタブ。タブ一覧を確認する |
| 撮影が `capture_dimensions_exceeded` | 範囲が各辺2,500pxを超える。表示範囲の撮影か、ページを小さくして撮る |
| 操作が `needs_input` で止まる | 案内文に操作か値が出ている。実行してよければ会話で同意を伝える（10分以内） |
| 同意しても続きが実行されない | 承認は同じ会話・10分以内・同じタブ・同じ要素の説明の操作にだけ効く。一度使うと消える。もう一度頼み直す |
| タブが「保護のため停止」 | 開けないアドレスを表示している。Braveで閉じるか別のページへ移し、必要なら接続し直す |
| 保存で `browser_executable_invalid` | パスに実行できるファイルが無い。Braveの実行ファイルの絶対パスを確認する |

`bun run logs -- --level warn` から始め、`browser.` で始まるイベントを見る。

## 確認

```sh
bun run toolchain:bundle -- check api/domains/capabilities/bundles/browser.bundle.json
bun test api/application/browser api/domains/browser/test
bunx vitest run web/src/domains/browser
bun run verify -- --domain browser --domain capabilities --domain tool-runtime --domain inference
```

操作の結合試験は固定モデル・固定driverを使う。MCP adapter試験は実ブラウザへ接続しないstdioの代替子プロセスを使う。`tests/browser/browser-workspace.spec.ts`はサーバーなしで既存ArtifactPanelと画面部品を組み合わせ、3つの幅で確認する。実機のBraveとBridgeでの受入、実LLMの担当選択と操作判断は別に記録する。
