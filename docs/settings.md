# 設定画面とサービスの試用

設定アーティファクトの「動作確認」では、LARM と登録済みクラウドの個別動作を確認できます。会話・音声・埋め込み・判断に加え、画像のプレビューと楽曲の試聴・保存に対応しています。「自己診断」は各接続型プロバイダの Health を確認し、画像・楽曲は起動せず要求時起動として表示します。入力済みのサンプルから実行でき、通常の会話やメモリーには追加しません。詳しくは [試用と自己診断の検証記録](../spec/verification/service-tests/README.md) を参照してください。

画像生成は、LARMのcatalogがcapability `media.image.generate` で広告するサービスを使います。Profile名・モデル名は固定せず、モデルの変更は「一覧を更新」で取り込みます。画像の幅・高さは各100〜1280pxの整数を別々に入力でき、初期値は512×512、形式はWebPです。写真風・イラストの品質や細部は描写欄で指定してください。生成中はモデルの起動・生成・停止を待ちます。APIの指定方法と所要時間の目安は [LARMの画像生成手順](larm.md#画像生成) を参照してください。

## 設定画面

アーティファクト一覧の「設定」から、会話、AIと接続、音声と入力、表示、記録などの画面を開けます。右上の歯車から開いていた従来の設定ページは削除し、設定はこのアーティファクトに一本化しました。

「記録」は「AIの利用」「ツールチェーン」の2タブです。主一覧と「保存済みの取得手順」はTanStack Tableで表示し、初期10件・25件・50件のページ切替、文字列検索、列見出しからの昇順／降順に対応します。検索・ソート・ページ切替はAPIが保持している全対象に適用し、指定ページだけを取得します。主一覧の詳細はモーダルで表示します。「記録を更新」でも検索などの条件を維持します。取得手順の有効化・無効化・確認付き削除は設定の共通保存を介さず既存APIで反映します。削除で最終ページがなくなった場合はAPIが前の有効なページへ補正します。「データと診断」セクションは表示しません。

### ワールドモデル（世界の状態の記録）

World画面は最初に「資料」を開き、取り込んだ原資料を総件数付きのTableで表示します。「資料」と「主張の一覧」は10件・25件・50件のページ切替、全対象の検索・並べ替えに対応します。資料検索は本文も対象にし、詳細モーダルでメタデータと本文の先頭2048文字を確認できます。主張は対象・主張・採用状態・由来・鮮度を一覧に並べ、条件、支持する根拠、反証、出典の版、履歴を各ページの詳細モーダルから確認できます。主張検索は一覧の5項目を対象とし、APIが部分取得を示す場合は取得できた範囲の表示です。「忘却の状況」もTableで確認できます。右上の丸は利用可能時に緑、オフ・利用不能・受付停止・通信断時に赤になります。

固定シード `grok-984-v1` は採用対象の原資料984件です。受領1001件のうち保留17件は含みません。資料の投入件数と、資料から抽出・採用した主張の件数は異なります。

「会話」の「ワールドモデル（世界の状態の記録）を使う」で、Personal World を使うかを設定します（保存先は設定の `world.enabled`、既定は無効）。環境変数 `EUMENES_WORLD` は廃止しました。**変更はbackendの再起動後に反映されます**（初回の同期と起動時の確認が起動処理のため）。

- オフで、Worldに内容が無い場合: Worldを組み立てません。従来どおりに動作します。
- オフでも、Worldに内容（登録した対象・主張・取り込んだ入力・忘却の依頼）が残っている場合: 起動時に自動で「保護」状態になり、忘却と訂正の反映だけが動きます。内容の読み書きは行いません。オフに戻しても忘却が止まることはありません。
- オン: 初回の同期を行ってから有効になります。

`EUMENES_WORLD_JOURNAL`、`EUMENES_WORLD_POLL_MS`、`EUMENES_WORLD_CURSOR_SECRET` は従来どおり環境変数です。詳細は [Worldの組み立て](../api/domains/world/README.md#assembly-apiapplicationworldts) を参照してください。

設定アーティファクトの「会話」「音声と入力」「表示」では、画面内の「設定の変更をすべて保存」から保存できます。共通下書きにある他の設定画面の変更も一緒に保存します。保存内容を確認する場合は「変更一覧を開く」を使います。保存中は再送を止め、失敗時は入力を保持して同じ画面から再試行できます。

「表示」は背景、テーマ、読み上げ字幕の有効化、字幕デザイン、字幕サイズを扱います。字幕のプレビューは未保存の選択を反映し、会話の背景・テーマ・読み上げ中の字幕は保存した値を使います。端末設定に合わせるテーマは端末の明暗の変更にも追従します。

「表示」の「会話の背景」では、光の妖精とSpatialを選び、「設定の変更をすべて保存」で保存できます。Spatialは現在、CPU・Memory・SSD・Networkの仮モデルを未確認状態で表示します。実測・Provider healthの接続は後続です。モデルの組込みは [背景とSpatial](backgrounds.md) を参照してください。

設定アーティファクトの「AIと接続」で、用途ごとの接続先とクラウド代替先を変更できます。LARMを優先し、接続不能・混雑・時間切れの場合は用途ごとに登録したクラウドへ自動で切り替えます。クラウドの送信許可と自動切替は初期値で有効ですが、代替先が未登録ならクラウドには送信しません。認証エラーや契約不一致、取消では自動切替しません。

クラウドはOpenAI互換のChat Completions、multipart音声認識、WAV音声合成に対応します。ベースURLは、ループバック・プライベートLAN（10/172.16-31/192.168）・`.local`・リンクローカル以外では `https` が必要です。環境変数名で指定できるのは `EUMENES_CLOUD_` で始まる名前、主要プロバイダの標準キー名（`OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`、`GOOGLE_API_KEY`、`AZURE_OPENAI_API_KEY`、`GROQ_API_KEY`、`MISTRAL_API_KEY`、`DEEPSEEK_API_KEY`）、およびbackendの `EUMENES_ENV_REF_ALLOWLIST`（カンマ区切り）に載せた名前だけです。それ以外を指す既存設定は保存したままですが、利用時に `env_ref_not_allowed` で失敗します。接続名、ベースURL、モデルとAPIキーまたは環境変数名を登録し、用途に割り当てて「設定の変更をすべて保存」を押します。一つの接続に複数の用途のモデルを追加できます。接続確認と少量の生成テストは保存済み設定を使い、サービスの利用が発生します。

### Cloudflare Workers AIの音声接続

「AIと接続」の既存画面から登録します。

1. 「登録した接続」で接続の種類を「Cloudflare Workers AI」にし、接続名・Account ID・APIトークンを入力して登録します。APIのURLは入力不要です。
2. 「設定の変更をすべて保存」を押します。APIトークンは既存の秘密情報用経路で暗号化し、設定取得・変更一覧・操作の保存記録には値を返しません。
3. 「音声モデル」で接続を選び、「接続確認・モデル一覧を更新」を押します。保存済みのAccount IDとAPIトークンを使ってbackendからCloudflareへ問い合わせます。未保存の接続変更やトークン更新がある間は取得・追加できません。
4. 用途を「聞き取り（ASR）」「読み上げ（TTS）」から選び、モデルと、そのモデルで指定できる声・言語を選んで「選んだモデルを下書きに追加」を押します。ASRとTTSを追加してから、共通の保存ボタンで保存できます。
5. 「利用するAI」の「聞き取りの利用先」「読み上げの利用先」で登録したモデルを選び、利用方法とクラウド送信の許可を確認して保存します。LARM優先の代替先にもクラウド専用先にも使えます。モデルの登録だけでは利用先を切り替えません。

「クラウドAPIを登録」は下書きへ追加する操作です。Account IDの形式やAPIトークンの未入力は、この段階で表示し、入力を残します。入力中の接続がある間は「保存済み」と表示せず、先に登録するよう案内します。下書きへの追加後に「設定の変更をすべて保存」を押してください。保存を拒否された場合も下書きを保持し、再試行できます。トークンの更新欄はパスワード入力として扱い、途中の挿入・削除でも値を保ちます。数値欄は空欄や小数点などの入力途中を保持し、値が有効になるまで保存を止めます。

登録直後から接続一覧に行を追加し、保存状態を「未保存」と表示します。画面上部の「設定の変更をすべて保存」を押すと、接続一覧を再取得して「保存済み」へ切り替えます。保存ボタンと結果の表示はスクロール中も確認でき、失敗時は未保存の行を残します。この表示は登録済みの列・actionと共通下書きから作り、接続の種類による専用画面は追加しません。

1つの接続をASR・TTSで共有します。モデル名・声の候補・言語の候補は実行時のcatalogと入出力schemaから取得し、コードにモデル名を固定しません。言語の候補が提供されないモデルでは言語コードを入力できますが、対応言語はモデルの仕様で確認してください。空欄ではサービスの既定を使います。

モデル一覧の取得成功と音声の動作確認は別です。現在の変換処理が扱える入出力形式のモデルだけを選択でき、未対応のモデルは理由を表示します。ASRはJSONの`audio`にBase64またはバイト配列を渡し、`text`を返す契約に対応します。TTSは`text`または`prompt`、必要に応じて`speaker`／`voice`や`lang`／`language`を渡す契約に対応します。WAV出力を指定できる場合はWAVを要求し、MP3出力はbackendの`ffmpeg`でWAVに変換します。`ffmpeg`がない環境では変換が必要なモデルを選べません。音声ストリーミングと別の入出力形式は今回の対応範囲に含めません。

Account ID・APIトークンの変更、接続の無効化・削除では、既存の接続世代による失効を適用し、古い一覧や実行結果を採用しません。従来のOpenAI互換接続やSDK接続はそのまま使えます。

APIの根拠: [Workers AIの認証](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)、[モデル検索](https://developers.cloudflare.com/api/resources/ai/subresources/models/methods/list/)、[入出力schema](https://developers.cloudflare.com/api/resources/ai/subresources/models/subresources/schema/methods/get/)。

### エージェントSDKの接続（会話用途のみ）

クラウドAPIの登録で「接続の種類」を選ぶと、OpenAI互換API以外に Codex SDK・Claude Agent SDK を会話（`llm`）の代替先・クラウド専用先として使えます。聞き取り・読み上げには割り当てられません。

| 種類 | 実行 | 認証 | 会話のツール呼び出し |
| --- | --- | --- | --- |
| Codex SDK | Codex CLI（ネイティブツール・プラグイン・MCP・履歴を無効化、一時ディレクトリで読み取り専用） | APIキー（`OPENAI_API_KEY`等）またはCodex CLIのログイン | 出力schemaで「返答」か「関数呼び出し」を選ばせる |
| Claude Agent SDK | Claude Code組込みツールを無効化し、呼び出しごとの一時設定ディレクトリで実行 | 認証方式を明示して選ぶ（下記） | 会話の関数をin-process MCPツールとして渡し、呼び出された時点でターンを終了 |

Claude Agent SDK の認証方式は接続ごとに選び、課金経路が分かれます。

- **サブスクリプション**: `claude setup-token` で発行したトークンを登録します（暗号化保存）。環境変数名では指定できません。ホストのClaude Codeのログインは使いません。
- **APIキー**: `ANTHROPIC_API_KEY` 相当のキー（または許可された環境変数名）と、ベースURLを登録します。

最初のメッセージを送る前に、SDKが報告した資格情報の種類を確認し、選んだ認証方式と一致しない場合（資格情報の混在を含む）は送信せずに失敗します。用途に割り当て済みの接続の認証方式・種類を、課金経路が変わる形で変更することはできません（`invalid_billing_path_change`）。認証方式を変えたときは新しい資格情報の登録が必要です。自動の代替（専用リソースが使えないときの会話経路への切替など）も課金経路をまたがず、またぐ場合はLARMだけで実行して `inference.route_billing_mismatch` を記録します。

接続で使えるモデルは保存済みの資格情報で実行時に取得します（`GET /api/inference/connections/:id/models`。接続確認を兼ねます）。会話画面左上のモデル選択は接続ごとに課金経路を示してグループ化し、選択は次の発言から適用されます。サブエージェント（研究worker・操作担当など）が使う接続は「サブエージェントの接続」で1つ選び、未選択ならLARMを使います。

関数の実行はどの種類でもEumenesが行い、エージェント側では実行しません。会話担当（`main`）のClaude Agent SDKセッションは、接続×認証方式×モデルごとに1つのセッションIDを使い続け、切り替えて戻せば以前のIDで再開します。履歴は毎回、会話台帳に保存された発言と採用回答から組み立てて渡し、SDKが書く記録は保存しません。忘却・取り下げ・要約は次の発言の履歴に反映され、忘却対象を参照して実行中の試行は中止されます。Claude Code の自動要約は無効化しており、文脈の予算は会話のWindowが管理します。サブエージェントはタスクごとに新しいセッションを使い、履歴を持ち越しません。それ以外の経路では、先頭のsystemメッセージを指示、残りを履歴として渡します。

LARMのURL・Profile・audience・voiceは初回起動時に環境変数から取り込み、以降は設定画面に保存した値を使います。Profileは未保存でも起動でき、保存するまでLARMには接続しません（`larm_profile_missing`）。選択肢は、保存済みの接続先のcatalogで `llm` Providerを持つProfileです。URLが空欄の間は未設定扱いで、LARMには接続しません。LARM認証とクラウドキーの環境変数はbackendだけで読みます。環境変数を変更した場合はbackendを再起動してください。

APIキーはAES-256-GCMで暗号化します。暗号鍵は32バイトをBase64にした `EUMENES_SECRET_KEY`、またはデータベースの隣の `keys/settings.key` を使います。未指定ならファイルを自動生成します。データベースと暗号鍵を一緒にバックアップしてください。既存の暗号文があるのに鍵が見つからない場合は再生成せず、保存済みキーによるクラウド利用を停止します。APIキーは設定取得や診断データに含めません。

送信許可の取消、キーの削除・更新、接続の無効化は実行中の結果にも反映します。読み上げの変更は次の発話、マイク・録音調整は次の音声開始から反映します。予約は一回と固定間隔に対応し、Eumenes起動中に実行します。予約を作成・停止する画面は従来の設定ページとともに削除したため、現在はAPI（`/api/schedules`）からのみ操作できます。予約の取消は今後の受付を停止し、受付済みの会話は実行記録から別途取り消します。

自動読み上げがONの場合、会話画面で新しく採用されたLLM回答を、文字入力・音声入力・外部API・予約の入力経路に関係なく読み上げます。マイクをONにしたままでも、同じ音声出力を使って再生します。生成途中や取消済みの回答は読み上げず、画面を開き直しても過去の回答を自動で読み直しません。ミュートは進行中の自動読み上げと待機中の回答に反映します。「読み上げ直す」による明示的な再生は引き続き利用できます。

実装と検証の詳細は [設定画面の検証記録](../spec/verification/settings/README.md) を参照してください。

音声の自動表現は全6候補へのモデル判定と `api/domains/delivery/data/speech-delivery.v1.json` のpresetを使います。本文の語句や句読点による速度・高さ・抑揚補正は行いません。判定失敗時は保存済み設定を維持し、`autoStrength`、`autoIntonation`、sample overrideと数値範囲の検査は適用されます。`autoIntonation` は未保存ならON、明示的に `false` を保存した場合だけ判定結果を声へ反映しません（表情判定とアバター動作は続けます）。調子は warmth・curiosity が bright、joy・surprise が excited、empathy が gentle、none が natural です。英語区間には適用しません。
