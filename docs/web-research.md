# 会話からの外部情報検索

会話中に答える必要がある天気・株価などは、会話エージェントが `lookup_public_information` を使い、Codex のライブ検索から得た値と出典を返します。検索条件は会話から組み立て、対象日時、場所や市場、単位を明示します。調査結果を後でメモとして残す依頼は `web.note` が扱います。

サイトを指定した検索や、アプリ作成で使うページ取得は、共有のWeb取得を使います。`web read --stable` で指定したページは専用SQLiteに保存し、`--fresh` で再取得できます。本文は未信頼の資料として検査します。 [取得部品の由来](../vendor/llm-fetch/manifest.json)
