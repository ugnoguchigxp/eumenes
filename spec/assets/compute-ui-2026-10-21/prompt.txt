Use case: ui-mockup
Asset type: one high fidelity desktop interface design proposal for Eumenes, a Japanese AI assistant app. This is a DESIGN CONCEPT, not a screenshot of an implemented feature.
Primary request: show how an AI computation specialist's completed result and artifacts can be reviewed beside the conversation, while the parent assistant uses the result in its answer. A clear, restrained, usable product UI for non-engineers. No programming IDE.
Composition: a single straight-on crisp wide desktop application screen, 16:10 landscape. Slim app top bar with Eumenes on the left, a subtle "画面を開く" button on right. Conversation column occupies left 36%, a thin draggable separator, calculation artifact workspace occupies right 64%. No global sidebar. Right pane has a selected tab "計算" with close X. Inside right pane narrow calculation history on the left and large selected result on the right. Keep enough room for readable Japanese text.
Existing visual system: softened light gray-blue background hsl(216 16% 92%), near-white cards hsl(216 18% 95.5%), dark navy text hsl(215 22% 15%), restrained medium blue hsl(214 72% 44%), subtle borders, 8px radius, modest spacing, fine outline icons, modern Japanese sans serif. No glass, no gradients, no giant marketing typography, no dark theme.
Conversation: user bubble says "このデータで傾向を調べて、グラフにして". Assistant response says "計算が完了しました。全体として右肩上がりの傾向です。グラフと計算結果を右側に表示しました。" Small successful tool activity chip "計算担当 · 完了". Normal composer anchored bottom "メッセージを入力".
Artifact heading "計算", muted subtext "結果・グラフ・実行履歴", small refresh icon button "更新". Narrow history has two entries: selected "データの傾向" with green "完了", and "分布の確認" with blue "実行中" and small stop icon. Selected result header "データの傾向" green "完了" with time "今日 14:32". A short result card title "計算結果" and body "データには正の相関が見られます。". The main visual is a polished but ordinary matplotlib style scatter chart with an upward blue regression line, title "データと近似直線", axes x and y, subtle grid, 20 blue dots. Below chart two compact downloadable file rows "figure-1.png" and "analysis.csv", each file type icon and outline "ダウンロード" button. A collapsed disclosure at bottom "実行したPythonコード", another "標準出力". Code is hidden by default. No code editor, no new job form, no automatic rerun or modify buttons, no model/profile names, no server URLs or implementation terminology in UI.
A small unobtrusive label outside the app at bottom right: "UIデザイン案". Prioritize readable Japanese, coherent spacing, and a convincing practical interface. Entire frame is a single app mockup, no perspective, no laptop, no surrounding desk, no multiple screens.
