Use case: ui-mockup
Create one high-fidelity flat desktop UI concept image, landscape 1280x960, for the existing Japanese Eumenes AI assistant. This is a proposed Markdown editing workspace inside the application's Artifact panel, not a marketing page. Dark charcoal background #181a20, surfaces #20242d, subtle borders #373d48, warm white text, restrained blue #5279ee accent. Crisp legible Japanese sans-serif, compact practical controls, comfortable document line spacing, no gradients or decorative art.
Composition: left 28 percent is the existing quiet conversation column; right 72 percent is a continuous large Markdown editor Artifact. Top has Eumenes branding small, then compact Artifact tab labelled 「Markdown」 with a close icon. The Artifact content has 8px outer spacing. Avoid extra card boxes around every paragraph. No additional AI chat inside the editor.
Conversation column: user bubble 「この文章を一緒に仕上げたい」, assistant reply 「下書きを開きました。右側で直接編集できます。」, another user bubble 「選択した段落を短くして」, assistant reply 「選択した範囲を整えました。」. At bottom a simple message composer.
Editor header: small document icon, title 「企画メモ.md」, a green dot with 「保存済み」. Right aligned quiet actions 「文書一覧」 「履歴」 and an overflow menu. Second row: a segmented switch 「編集」 (active) and 「ソース」; minimal formatting toolbar with heading selector, bold B, italic I, list, link and code icons; a restrained blue button 「選択範囲をAIへ」.
Document body: spacious readable sheet on dark background. Heading 「小さく始める、共同編集」. A paragraph explaining that a person can write and AI can refine a selected part. One paragraph has a subtle pale-blue selection highlight and a tiny inline label 「AIが編集」, without approve/reject buttons. Next heading 「最初にできること」 followed by three short checklist rows 「自分で文章を編集する」 「会話からAIに修正を頼む」 「Markdownで持ち出す」. Below a simple two-column Markdown-style table, then a small dark fenced-code block. Keep this a useful real document, not a dashboard.
Bottom status bar: 「Markdown」 「1,248文字」 on left, 「自動保存」 on right. Distinguish this generated design proposal with a small unobtrusive caption 「画面案」 outside the app frame. No pricing, no technical API names, no extra sidebars, no fake analytics, no huge headings.
