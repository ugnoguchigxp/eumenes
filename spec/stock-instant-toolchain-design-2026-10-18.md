# 株価の即時回答ツールチェーン

作成日: 2026-10-18

状態: 2026-10-18 実装・fixture済み（`api/application/stock/`、bundle `stock-quote`）。実LLMでの選択と製品での確認は未。Yahoo検索APIは日本語の検索語を400で拒否するため、日本語名はEDINETだけで解決する（実装時の調整）。同順位の候補は資本金の大きい順（§5 S4、2026-10-18 合意）。[天気の即時回答](weather-instant-toolchain-design-2026-10-18.md) の「即時回答」型の上に作る。

## 1. 背景

株価の依頼も、天気と同じく汎用のWeb調査を通って数十秒かかる。答えの形が決まっているので、専用の担当で即時に答える。

## 2. 使うデータ（2026-10-18 確認）

| 用途 | 呼び先 | 確認結果 |
| --- | --- | --- |
| 株価 | Yahoo のチャートAPI `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?range=1d&interval=1d`（yfinance が内部で使うもの。Bun から直接呼ぶ） | `9434.T`: SoftBank Corp. / JPY 244.7（前日終値242.7）/ JPX、約0.27秒。`AAPL`: Apple Inc. / USD 343.46（前日終値342.0）/ NMS、約0.26秒。User-Agent が必要 |
| 日本株の名前→証券コード | EDINET コードリスト `https://disclosure2dl.edinet-fsa.go.jp/searchdocument/codelist/Edinetcode.zip`（APIキー不要、CP932のCSV） | 約0.21秒、11,423件。提出者名（漢字・英字・ヨミ）と証券コード（5桁、例 94340→9434→`9434.T`） |
| 米国株などの名前→ティッカー | Yahoo の検索API（`/v1/finance/search?q=`） | 実装時に確認 |

いずれも非公式または用途外の利用を含む。利用者方針により利便性を優先して使う（§5 S1）。

## 3. 流れ

| 段階 | LLM | 内容 |
| --- | --- | --- |
| 候補検索 | なし | 既存（会話の初動 §8） |
| R1 | 1回 | 株価担当の関数を呼ぶ。引数は共通の kind/freshness/impact/approved と `query`（言われた会社名・ティッカーをそのまま）。`announcement` は持たない |
| 解決 | なし | 並行して、EDINET コードリスト（上場・証券コードありの行）で名前照合（漢字・英字・ヨミ）と、Yahoo 検索APIで照合。日本株で見つかれば日本株を優先（S3）。同名候補は完全一致→前方一致→部分一致の順で1社に決める（S2） |
| 取得 | なし | Yahoo のチャートAPIで価格・前日終値・通貨・取引所・時刻を取得 |
| 回答 | なし | 決まった形の文。例「ソフトバンク株式会社（9434）の株価は244.7円、前日比+2.0円（+0.82%）です。10/17 15:30時点。」正式名とコードを必ず入れ、利用者が別銘柄だと気づけるようにする |

- EDINET コードリストは取得してキャッシュし、一日に一回程度更新する。
- 文の形・照合の規則・データの取得はツールチェーン側（登録定義・adapter）に置き、会話の共通 SystemContext には足さない（天気と同じ）。
- 取得・照合の失敗（ネットワーク、非200、形式不正、銘柄が見つからない）は、同じ run で既存の `web.search` へ切り替え、元の発言を依頼として渡す。一時回答は出さない（天気と同じ）。

## 4. 対象外

履歴チャート、指標・財務情報、ニュース、複数銘柄の比較は扱わない。登録定義の useWhen/avoidWhen で Web 調査を選ぶよう示す。

## 5. 決定事項

| ID | 論点 | 決定 |
| --- | --- | --- |
| S1 | 非公式APIの利用 | 使う。常に利便性の良いものを使う |
| S2 | 同名候補が複数 | 完全一致を優先し、なければ最も近い1社で答える。回答に正式名とコードを入れる。確認は返さない |
| S3 | 日本・米国の両方で見つかる | 日本株を優先 |
| S4 | 一致の度合いが同じ候補が複数（例「トヨタ」→トヨタ自動車・トヨタ紡織） | EDINET コードリストの「資本金」が大きい会社を選ぶ（追加の通信なし）。時価総額は Yahoo の quote API が認証（crumb）を要し候補ごとの問い合わせになるため使わない。順序は 一致の度合い → 日本株 → 資本金 → 名前の長さの近さ → 見つかった順 |
