# Works P1 検証

2026-11-28 JST。製品外のループバックに、認証付きのWorks APIと実際の本体Webの `#works` 入口を組み合わせた。依存の正本、固定版の導入先、作品Git、外部clone、Webビルド出力、登録情報はすべて一時ディレクトリ。製品サーバー、製品DB、LARMには接続していない。

| 項目 | 検証結果 |
| --- | --- |
| Gitと依存 | 新規3D作品を画面から作成し、画像一覧の試験用リポジトリを登録した。二つのGitルートと履歴が独立し、作品の作成と編集でCoreのGit状態が変化しなかった。両作品と外部cloneに個別の `node_modules`、ロックファイルは0件。 |
| Eumenes内 | macOS版Google Chromeで2作品を同じループバック配信口から表示。3D描画、GLTF、画像、CSS、作品別の保存領域を確認。無認証のAPI、作品からの本体API、Service Workerを拒否した。 |
| 保存と失敗 | 保存すると同じ作品だけが更新された。型エラーで診断を出しつつプレビューを更新し、ビルド失敗では直前の表示を維持した。巨大ファイル、ルート外リンク、未導入版の状態を確認した。処理中の作品を止めても別作品を開けた。 |
| 移設と終了 | 移設後も作品IDとブラウザー保存を保ち、古い配信URLは失効した。登録解除で作品のGit状態とリモートは変わらず、両方を閉じると監視と処理中のビルドは0件。 |
| 単体 | Eumenes側の試験サーバーを停止後、外部cloneした2件を同じ固定版で `typecheck`、`build`、`dev` まで実行した。素材と再読込み後の設定が見え、本体宛て通信は0件。型エラーのある `build` は失敗し、共有環境未指定時には設定名を案内した。 |

受入作品は試験データ。実作品の試験移行はP4、会話からの制作と実LARM接続はP2・P3で扱う。

一時コピーで `verify --domain prototype` に合格した。APIとサーバーの既存回帰試験は26件合格。ブラウザー受入は静的素材、作品内保存、移設、停止、単体実行まで完了し、試験で起動した待受はすべて停止を確認した。 [ブラウザー受入の結果](result.json)

bun run verify -- --domain prototype
bun --no-env-file spec/verification/instant-project-sandbox-p1-2026-11-28/acceptance.ts
