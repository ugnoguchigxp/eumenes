追加レビューと改善を完了した。[最新のレビュー結果・検証記録](review.md)を参照。以下は初回実装時の記録。

2026-10-22。利用者が承認した[小型モーダルと別選択画面の設計](../../design/pipeline-studio-2026-10-22/handoff-modal-design.md)を実装した。

## 実装した動作

各手順カードの「渡すものを編集」で、幅400pxを上限とするアーティファクト内のモーダルを開く。画像・楽曲・前の結果・入力項目の一覧は、同じアーティファクトの別画面に切り替える。会話欄とホストのタブを覆わず、別モーダルも重ねない。

本文、固定のJSON値、実行時の依頼文、前／現在の手順のプロンプト原文、前の結果全体／実際の試験出力の項目、保存画像・楽曲を複数選べる。本文の改行・空白、値の型、0・false・空文字・nullを保持する。実行時依頼は毎回解決し、手順の原文プロンプトは再展開しない。内部のシステム指示を取り出す機能はない。

画像は共有ImagePicker/ImageGrid、楽曲はPlaylist/MusicPlayerを再利用した。認証済みの既存一覧APIと同一オリジンのメディア取得先へ接続し、選択結果には本体IDを保存する。選択だけでは再生せず、戻るとプレイヤーを破棄する。画像の選択専用画面にはアップロードや利用できない外部提供元の入口を表示しない。

選択画面の取消はその画面の変更を採用せず、モーダルへ戻る。モーダルの取消は全ての未確定変更を捨てる。「反映」だけが既存のsource applyを呼ぶ。元のworkRef・revisionから別の下書き／版へ変わると上書きしない。Escape・枠内のTab移動・閉じた後のカードへのフォーカスを扱う。

## 接続と責務

- `PipelineStep.materials` と既存の `ChildExecution` に任意データの受け渡しを追加。従来の文字列テンプレート展開は資料の全文受け渡しに流用しない。
- pipelines domainが契約・先行関係を検査し、実行時の参照を解決する。意味判断や資料からの命令生成は実装していない。
- commandは独立したmaterials、researchは参考データのpipelineMaterialsとして渡す。メディア担当は既存の子実行データを通して受け取る。型や任意形式の内容をどう使うかは既存のLLM担当に残す。
- 参照不存在や資料全体16,384バイト／既存の子実行24,576バイト上限は明示的に停止する。省略して続けない。instantは正式なargumentsだけを受け取るため、materials付きの定義は公開検査で拒否する。
- toolchain・package・skill・binding・artifactの `pipeline.studio@2` とローカル選択操作のschemaを追加。profileは従来版を再利用。旧revisionの全オブジェクトがHEADの登録内容と同一であることを比較した。
- 公開、版検査、ワーク保存、認証、音楽再生、画像デコードの共通機構を再利用。DBスキーマ、新しい判断方式、ループ・分岐、自動変換は追加していない。

## 検証中の問題と扱い

初回の登録検査では新しいローカル操作のinput schema宣言漏れを検出し、専用schemaを追加した。旧版を固定していた会話結合試験は、有効な新版を開くよう更新した。型・lintで検出した部品分割後の戻り値とキーボード／labelの問題を修正した。

広いverifyは担当外の `generation-prepare.ts`、Artifact UIの既存3ファイルのサイズ上限で停止した。それらを修正せず、関連4domainへ範囲を分けた。途中の4domain検証は全試験成功後に並行する別作業の入力更新でinvalidatedとなったため成功扱いせず、その後の固定された入力で正式なpassを取得した。

容量境界の会話fixture試験は終端状態を確認できず待機時間切れとなった。対象を実行層の入力境界へ絞り、実DB・実キューで子呼出しを検査する試験へ変更して成功した。期待する上限や停止動作は弱めていない。

3ラウンド後の俯瞰評価では、既に成功した資料の保存・実行・画面操作と、担当外の検証停止を分け、検証範囲を変更する方針を通知した。以後、原因が分かった修正と接続部分の試験に絞り、関連domainのpassとブラウザ成功を得た。

今回の実装ラウンド：context_compile 1回、compile_eval 1回（useful）。実装・固定試験・ブラウザ受入は完了。サーバーの起動・停止・再起動、製品DB・設定変更、別チャットへの送信は行っていない。
