# 調査メモ3段階・全文保存の検証（2026-11-15）

設計は[承認済み設計](../../research-note-levels-and-okf-design-2026-11-15.md)。YAMLは利用者の追加指示により実装しない。保存物は再利用用Markdownであり、OKF仕様準拠とは扱わない。

## 実装

- 会話の追記は2文・102文字。入口は既存の `start_preparation(request, askedByUser)` のまま。通常・自発的な下調べは短め。希望の意味は調査LLMが解釈し、語句で振り分けるコードは追加していない。
- `skill:web.note@3` → `package:web.note@4` → `toolchain:web.note@4`。新出力schemaとbindingはrevision 2。実行上限64KiBとschema上限の不一致を解消し、固定モデル・実行期限・入力schema・adapterは維持。旧bundle全体の内容hashが不変なことを固定試験で確認。
- 採用と生成文書受付は同じtransaction。原文を保存してからcheckpointだけを8,000文字以内にする。普段の一覧は要約のみ。明示的な読取りでは原文を返し、ライブラリの4,000文字切り詰めを避ける。資料としてのエスケープ、入力検証、利用記録は既存機構を使用。
- 文書が見つからないときに短縮版から再作成しない。従来の文書IDなしメモも読める。保存先は既存の `eumenes` / `notes/`。全文・条件・日付・出典を保持する。
