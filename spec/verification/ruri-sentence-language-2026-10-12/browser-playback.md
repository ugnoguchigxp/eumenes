# 日英の実ブラウザ読み上げ

2026-10-12 19:11–19:12 JST。通常環境のBrave会話画面で、実LARMの回答LLMに日本語3文と英語3文を自然文で返すよう依頼し、採用された回答の「読み上げ直す」をそれぞれ操作した。言語タグは要求していない。

| 確認項目 | 結果 |
| --- | --- |
| 日本語 | VOICEVOX / voicevox-core / 剣崎雌雄、4区間すべて succeeded・accepted=1 |
| 英語 | KittenTTS / kitten-tts-nano-0.8-fp32 / Rosie、3区間すべて succeeded・accepted=1 |
| Ruri | 各回答の最初の区間で1回、計2回の公開System One要求。後続区間は全文の判定を再利用 |
| 再生 | 実AudioContextがrunning、音量1、通常の既定出力へ接続。7区間すべて開始と自然終了を観測 |
| 日本語の次区間開始 | 前区間の終了通知から64.7 / 63.5 / 46.8ms後 |
| 英語の次区間開始 | 前区間の終了通知から44.2 / 63.2ms後 |
| 重複 | 開始→終了→次開始の順序を全7区間で確認。再生の重なり0 |
| 関連単体試験 | Vitestでaudio / replayの26件成功 |

日本語は既存の句読点分割により、読点を含む3文が4区間になった。英語は3文が3区間になった。合成は次の区間を先行して取得するが、再生は前区間の終了を待つ。同じ公開Connectionで両TTSを利用した。

開始・終了は既存AudioControllerに一時的な観測行を加え、Web Audioのstart / onendedで採取した。本文、音声、資格情報は観測ログに含めていない。観測行は削除済みで、ファイルが作業前と完全に一致することを確認した。製品動作・判断・公開APIの変更はない。対象試験は一時観測ありの状態で実行し、削除後は完全一致確認で復元を検証した。最初にBunでWeb試験を実行した際はViteのworker URLを解決できず実行エラーとなったため、正規のVitestで検証し直した。

今回の成功は、通常画面の再読み上げから実TTS・実Web Audio出力まで。最初の試聴時はユーザーが外出していたため聞き取り未確認だった。日本語→英語を再度再生し、ユーザーから「大丈夫ですが」と確認を得た。同時に日英で声の性別が変わる点の改善依頼があり、下記の女性声設定へ変更した。実マイクを使った音声会話の3往復、再生中の実発話割込み、生成途中の発声、混在文内の言語切替の受入には数えない。製品コードの恒久変更がない再生確認では全体gateを再実行していない。前回記録の担当外gate失敗も解消扱いにしない。

証跡: [再生イベント](browser-playback-events.json)、[合成採用記録](browser-playback-usage.json)、[確認画面](browser-playback.png)。ContextStillは今回compile/eval各1回、累計各8回。runId `00000000-0000-0000-18dd-c06d85062a86`。

## 女性アバターの日英音声を揃える

以下の可変設定とUIは、同日20時の追加指定で廃止した。現在は固定対応と英語速度1.0で、追加設定欄はない。[現行の固定動作](fixed-voice-pair.md)を参照。

同日19:47 JST、通常環境のsettings APIでrevision 19へ保存。日本語は剣崎雌雄から春日部つむぎへ、英語は未指定の既定声からRosieの明示指定へ変更した。両声の `voice_presentation=feminine` と日本語のdefault_styleを公開catalogで確認した。速度・高さなど他の設定は保持した。実APIの合成で日本語92,716 bytes・英語192,844 bytesを取得し、声のID・モデル・succeeded・accepted=1を確認した。[合成記録](female-voice-pair.json)。

英語の声選択欄にも既存の男性・女性・中性の表示を再利用し、通常画面で春日部つむぎ（女性）とRosie（女性）が選択され、変更保存済みと表示されることを確認した。[設定画面](female-voice-settings.png)。人物や声名から性別を推測する処理は追加していない。現行アバターは一種類で、アバターの性別切替設定や自動連動機能はない。男性声は日英とも公開catalogから手動で組み合わせられる。

settings gateはbackend21件・Web33件、境界・サイズ・format・lint・型検査・入力hash一致まで成功（6,682ms）。root型検査と対象Web4件も成功。初回gateは別の検証実行中で開始できず、終了後の再実行が成功した。恒久コード変更は英語の選択肢の表示だけでsettings内に閉じるため全体gateは再実行していない。ContextStillは声設定の作業でcompile/eval各1回、累計各9回。
