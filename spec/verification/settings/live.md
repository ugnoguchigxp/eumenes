# 設定画面の実サービス検証

2026年10月8日。export済みのLARM認証とbackend既定のLARMを使い、一時DBに初期設定を保存して新しいsettings/inference経路を検証した。製品DB・設定・秘密をコピーしていない。入力は「こんにちは。設定画面の接続テストです。」を合成したWAVで、ASRに「こんにちは」が含まれることを確認した。

| 用途 | 結果 | 一回の測定 |
| --- | --- | --- |
| ASR | LARMで採用、期待語を認識 | 897ms |
| LLM | LARMで回答を採用 | 3334ms |
| TTS | LARMでWAVを生成・採用 | 1446ms、753708bytes |

一時DB・暗号鍵は終了時に削除した。実サービスのcredentialや認識全文・回答本文は記録していない。これらは各一回の個別疎通であり、応答性能の保証や実マイクによる循環受入ではない。

実クラウドのテスト用認証は登録していないため、実クラウドAPIの三用途とLARM停止・回復を組み合わせた受入は未実施。通常のverifyはfixtureのみを利用する。live実行の補助は今回一時スクリプトで行い、既存verify:liveの対応domainはlarmのまま維持した。
