## 変更内容

- 元のモデルの局所寸法を1.35倍へ拡大した。原本bin・点数29,952・粒子サイズ・光量・health色は変更していない。
- 一律の最大拡散半径＋公転半径による大きな正方形の画角を廃止し、各点の実際の拡散範囲から回転不変の半径・深さを計算する。計算は形状設定ごとにキャッシュする。
- 横長は投影した横軸・縦軸の別々の範囲で画角を決定し、斜めの銀河を広く表示する。縦長は上からの構図にし、幅に収める。フォーカスでも対象の実寸を使う。
- 「状態を見る」ボタンを削除。状態プレビューのモデル選択はCanvasのクリック／矢印キーへ移し、再クリック・Esc・全体に戻るで復帰する。会話背景は会話操作を邪魔しない。
- 会話画面の「会話モデル」selectを読み取り専用の表示名に置き換えた。AI利用先の設定・保存値・設定画面の選択肢は残した。
- タイマーや関係のない機能には変更を加えていない。コミット・プッシュしていない。

2048×862と1280×720の通常条件では、カメラの投影倍率とモデル寸法を合わせて、各シェイプの横幅は計算上約1.85倍になる。全体も横へ広がる。縦画面は全体を収めるため拡大量を抑える。これは実機性能の測定値ではない。
