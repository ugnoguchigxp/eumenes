# Toolchain コードレビューと修正

2026-10-09。対象は新規 capability / tool-runtime / agent-runtime と、application・会話・Web・CLI・画面への接続。既存のメモリー更新など、今回の実装と関係しない変更は対象外。

## 再現して修正した問題

| 問題 | 修正・回帰試験 |
| --- | --- |
| 取消transactionをrollbackした後、別rootの取消が最初のrootの推論も取消す | DB更新対象をその取消操作のローカル集合に限定。2つのrootを動かし、Aの取消rollback後にBを取消してもAが完了するAPI試験 |
| 結果保存のrollbackでメモリーvaultに孤立した結果が残り、64件の容量を消費する | 所有者をvaultにも保持し、割当時にDB状態・期限・digestを再検査。64回rollbackした後の正常保存を試験 |
| 依存を停止して再開すると、停止前の候補参照が再び使える | 候補発行時に依存closureのrevision/hash/generationを固定。古い候補は永久失効、新しく検索した候補だけが使える試験 |
| 選択していないprofile/SKILLが子の指示へ混入し、必須SKILL欠落も検出できない | packageが指定したprofile・必須SKILLだけを展開し、欠落・空の本文を拒否。無関係な指示が入らない試験 |
| `^GSPC` のURLエンコードが取得元検査で拒否され、似たtickerの依頼範囲判定も広すぎる | 固定endpoint内でtickerを復号して許可文字を検査。`^GSPC`、`GSPC`、`AAPL.X`、文末の句点とencoded slashの境界を試験 |
| 削除・保持期限終了後も、画面にキャッシュ済みreportが残る | 永続taskのreportStateを表示条件とし、削除・失効時にreportキャッシュを除去。表示後の削除をWeb試験 |
| 取得失敗通知まで処理したrootが画面では「完了」と表示される | errorCodeを持つ完了rootを「取得失敗」として表示。子がない失敗でもcardを隠さず、reportを再取得しないWeb試験 |
| taskが失敗・取消済みでもstep台帳がqueued/runningのまま残る | 終了処理で未完了stepも終了。JSON・根拠修正を使い切った際の台帳を試験 |
| live E2Eが数値の存在だけで合格し、出典と違う価格・気温でも通る | 引用内の数値、子の主張、最終回答の一致を検査。正しい数値に架空値を併記した回答も拒否。株価の日付は日本語のゼロ埋め・省略年を含めて出典と照合 |
| APIは8,000文字を受け付けるが、子への入力契約は2,000文字で長い依頼が失敗する | 元依頼を8,000文字まで保持。package revision 2を追加しrevision 1のfingerprintは変更しない。Context全体は64KiB、必須指示と元依頼を残し任意の観測だけを削減。長い依頼のAPI試験とエスケープ文字を含む容量試験 |

実行前に失敗を確認した再現出力は、Git対象外の `verification-reports/toolchain/review-before.txt`、`review-ui-before.txt`、`review-ledger-before.txt`、`review-long-before.txt`。修正後の個別出力は `review-*-after.txt`。引用の完全一致に加えて意味まで正しいことを、これらの試験で証明したとは扱わない。

## 最終検証

関連9 domain（capabilities、tool-runtime、agent-runtime、web-research、queue、inference、larm、dialogue、voice-dialogue）の個別gateは全件合格。`bun run verify:all` はformat・lint・型・domain境界・build、backend **363/363**、Web **94/94**、browser **16/16** が合格（106.1秒）。修正後のcode revisionは `28fe49e32e8785aabedeef4806dd99038771a5cc46fc3ac9550a76a601c19055`。全体gate中のsource変更はなく、工程別結果は `verification-reports/latest.json`、出力は `verification-reports/toolchain/all.txt`。`git diff --check` も合格。

実LARM＋公開Webの隔離backend・認証付きAPI E2Eは20:50〜20:51 JSTに **2/2成功**。東京の翌日（2026-10-10）の晴れ・最高26度を取得し回答した（29.0秒、推論4/tool1）。AAPLは340.42 USD、2026-10-08 16:00 America/New_Yorkの値を取得し、価格と日付を回答した（34.8秒、推論5/tool1）。引用・子の主張・最終回答で値が一致し、価格日付も一致した。価格・予報は試験時点の値である。生出力は `review-live-final.txt`、公開結果は `live.json`。

直前のliveでは価格は一致したが、回答の「26年10月8日」を検証器が四桁年のみ対応のため拒否した。出典と同じ年の省略表記を受け入れる回帰試験を追加し、上記最終実行をやり直した。誤った日付や、正しい値と架空値の併記を許可する緩和はしていない。追加したContext試験の内部domain参照も境界gateにより検出し、公開API経由へ修正した後に全gateを再実行した。
