# picsum テーマ目録の作業記録

確認日: 2026-10-17。対象: [UI自由制作の表現力拡張](../ui-studio-expressive-parts-implementation-plan-2026-10-17.md) §4.1。正本は [picsum-themes.ts](../../packages/artifact-ui/src/picsum-themes.ts)。

## 手順

- `https://picsum.photos/v2/list?page=1..12&limit=100` から993件（ID 0〜1084、欠番あり）を取得した。
- 全件の縮小画像（240×160）をIDを書き込んだコンタクトシート29枚にまとめ、全件を目視で分類した。作業用ファイルはリポジトリ外。
- 採用した282件（重複を除く）について、`/id/<id>/800/450` がHTTP 200を返すことを確かめた。元画像が小さいID（195・311）でも、2400×1350・2400×2400・1600×2400、およびblur・grayscale付きで200を返す。リダイレクト先は `fastly.picsum.photos`。
- ID 0 は正の整数の要件に合わないため使わない。

## 除外の方針

- 顔が大きく写る人物は people 以外に入れない。people も後ろ姿・横顔・小さな人物を中心にした。64（サングラスの女性）と822（親子）は顔がやや見える。
- 水中・ダイバー、体の接写、群衆（球場・人混みの浜辺・バー）、看板・旗・宗教や政治のモチーフ、暗く不明瞭な画像は除外した。1082（ピアノの手）と1066（赤ちゃん）は使わない。
