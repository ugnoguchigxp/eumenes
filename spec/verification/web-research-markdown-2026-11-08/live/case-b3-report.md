# 東京国立博物館・国立科学博物館の常設展示における撮影ルール比較

## 比較

| 項目 | 東京国立博物館 | 国立科学博物館（上野本館） |
|---|---|---|
| 常設展示の写真撮影 | 東博コレクション展（平常展）は個人利用に限り写真・動画撮影可。 | 撮影者本人が個人的に使用する場合、原則自由。カメラ・スマートフォンは手持ち。 |
| フラッシュ | フラッシュ・追加照明の使用は控えるよう案内。 | フラッシュなど光を発するもの、追加照明は使用不可。 |
| 三脚 | 一脚・三脚の使用は控えるよう案内。 | 一脚・三脚は使用不可。 |
| 自撮り棒 | 使用は控えるよう案内。 | 自撮りスティックは使用不可。 |
| 展示ごとの例外 | 撮影禁止マークのある作品は撮影不可。特別展会場は原則として撮影禁止。 | 撮影禁止表示のあるもの、館内上映動画、シアター３６○内の映像は撮影禁止。特別展・企画展は会場入口の掲示ルールに従う。 |

## 補足
両館とも個人利用を前提とした撮影案内ですが、機材の表現は異なります。東京国立博物館はフラッシュ等や一脚・三脚、自撮り棒の使用を「お控えください」とし、国立科学博物館は撮影補助機材やフラッシュ等を「できません」としています。

国立科学博物館は、他の来館者の迷惑や権利者の権利侵害を避けるよう求め、団体集合写真も不可としています。東京国立博物館の確認した案内本文には団体集合写真の扱いの記載がありません。

## 未確認事項・限界
ここでの比較は各館の上記公式案内本文に基づきます。東京国立博物館について、個別作品の撮影可否は撮影禁止表示の有無によるため、個々の展示の表示までは確認していません。また、両館とも特別展等には個別ルールがあり得ます。東京国立博物館は特別展会場を原則撮影禁止と案内し、国立科学博物館は特別展・企画展ごとに会場入口の掲示を確認するよう案内しています。
