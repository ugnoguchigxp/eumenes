# Workspaceの分割と全変更の検証

2026-10-12。巨大になったAppの構成ファイルを分割し、全未コミット変更が全体検証を通った場合にcommit・pushする依頼。

## 分割

`web/src/App.tsx` は814行から23行へ縮小した。依存の生成とProviderの設置を残し、既存の画面構成・処理を次へ移した。

| ファイル | 責務 |
| --- | --- |
| `web/src/workspace/Workspace.tsx` | 設定・会話・成果物・字幕・タイマーの配置 |
| `web/src/workspace/useWorkspace.ts` | 既存query、通知、音声、入力、スクロール追従、設定遷移の状態管理 |
| `web/src/workspace/ConversationPanel.tsx` | 接続状態と会話履歴、回答中の表示 |
| `web/src/workspace/ConversationComposer.tsx` | 入力、送信、マイク、ミュート、経路とエラーの表示 |
| `web/src/workspace/WorkspaceArtifacts.tsx` | 成果物を開く既存操作とタブの描画 |
| `web/src/workspace/SettingsContent.tsx` | 設定と各パネルの遅延読込み |

既存のAPI・domain・state storeを再利用した。状態の正本やポーリング、個別語句の判定、LLM指示は追加していない。入力編集とスクロール時のref更新は所有するhook内の操作にまとめ、子コンポーネントからstateを直接変更しない。

サイズbudgetと試験の期待値は緩めていない。分割ファイルのサイズ検査・lintが通り、分割前後とも既存App試験3件が成功した。[分割前](app-before.txt)、[分割後](app-after.txt)。

## 結合検証と最小修正

分割後に、空の成果物コンポーネントを渡すと内容がなくても分割ペインが残ることを確認した。呼出し側でタブがある場合だけ渡し、Appの初期表示試験にも空ペインがないことを追加した。成果物のサイズ変更・キーボード操作・最後のタブを閉じる試験2件が成功した。[ブラウザ記録](artifact-browser.txt)。

利用者の明示承認により、固定ボタンを避ける右余白を成果物ヘッダーから内側のタブ領域へ移した。ヘッダーのpadding 0と本文のp-2という既存の期待値は維持した。

既定プロファイルの変更に合わせ、ブラウザ用LARM fixtureが要求されたOrnithのプロファイル・モデル・コンテキスト長を返し、接続ごとに保持するようにした。製品の契約検証は緩めていない。音声入力試験ではマイク準備の完了を待ってから入力を開始するようにし、3断片から1件の依頼と回答という期待値を維持した。[音声入力記録](voice-input-browser.txt)。

音声・設定の結合試験で、画像・音楽専用プロファイルにもGemmaの会話用Providerを掲載していたfixtureの不整合が顕在化した。専用サービスのカタログには会話用Providerを含めず、既存の自己診断の期待値（正常3・実行時に起動2）を維持した。[自己診断記録](health-browser.txt)。

途中の全体検証ではバックエンド1633件、Web 328件、client 317件、design-system 1109件、ビルドまで成功し、ブラウザの検索1件が送信クリック待ちで時間切れになった。単独の同じ検索試験2件は変更なしで成功したため、条件や製品コードは変更していない。[単独記録](toolchain-browser.txt)、[途中の通し記録](verify-all-before-final.txt)。この通し検証中に設計資料が変更されたため、検証入力の一致を満たす最終結果としては扱わない。

## 全変更の確認と残作業

全体検証の途中では、同じ作業ツリーで背景表示・Three.js型の変更が進行していた。利用者から別作業が進行中と確認を得たため、その完了を待って同じ入力状態で全体検証を行う。途中のdomain一覧の不一致は、登録を正本として公式の生成処理で更新した。背景モデルの型エラーは調査のみとし、担当側へ変更を加えていない。

タイマーを含む別作業は完了した。全32 domainの `verify:all` が成功し、backend等1633件、Web335件、client317件、design-system1109件、ブラウザ46件成功・実マイク依存1件の既定スキップを確認した。[全体検証ログ](../timer-launcher-2026-10-12/eumenes-timer-launcher-all-final.log)。

その後の変更は検証記録の追記で、全変更のformatと差分チェックも成功した。追記後の入力hashまで揃えるために開始した最終再実行は、利用者の「さっさとcommit push」「べつにe2e通さなくてもいい」という明示指示で中断した。その再実行でもsize・境界・domain docs・format・lint・型検査は成功していた。中断した実行を通し検証成功とは扱わない。

利用者の依頼どおり、他作業の成果と設計資料を含む全変更をcommit・pushする。Gemmaの選択肢と保存済みの明示選択を保持し、Ornithの実接続結果は別の[報告](../ornith-profile-2026-10-12/README.md)に記録した。
