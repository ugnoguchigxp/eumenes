# ASR入力試験用音声

`asr-utterance.wav` は「こんにちは。これは音声のサンプルです。」という合成音声。2026-11-15に、保存済み設定を使うEumenesの `/api/voice/sample` で生成し、PCM16・mono・16 kHzへ変換した。実際の利用者の録音・会話は含まない。

音声クレジット: VOICEVOX:春日部つむぎ

長さ2.816秒。製品と同じ発話検出モデルで88区間中65区間が発話確率0.5以上となることを確認した。ブラウザー試験ではMediaStreamへ供給し、ブラウザーは `--mute-audio` を指定する。ASR本文は試験用LARMが返すため、認識精度の評価用ではない。
