## 骨格

`skeleton.ts` がコードで29本のボーンを組む（`hips`・`tail_01..03`・`spine`・`core`・`chest`・`neck`・`head`・`crown_01..03`・`eyes`、腕4本×`01/02/03/tip`）。名前は動作データと将来のglTFとの共通名で、変えない。重みは手続きで付け、殻・光の幕・金線・腰の膜・体の粒子は高さ、腕のリボン・線・粒子は曲線上の位置で隣り合う2本へ振り分ける。粒子と線もボーン行列のfloat textureから同じ方式で変形する（Three.js標準の `Points`・`Line` はスキニング非対応のため自作）。光の核とその軌道・目・腕先の光はボーンの子として付ける。

## 動作

| 層 | 場所 | 内容 |
| --- | --- | --- |
| 待機 | `idle.ts` | 呼吸・浮遊・揺れ・羽と炎のゆらぎ・瞬き。表示全体の時計で動き、句の切替で巻き戻さない |
| 状態・感情 | `motions/*.json` | 1動作1ファイル。変化版を動作ごとの再生回数で連続しないよう選び、速度を0〜15%速める（遅くすると8秒の復帰で途中が切れるため速める側だけ）。切替は0.7秒のクロスフェード |
| 発話 | `motions/speaking.json` | 発話中に重ねる（待機は全量、うなだれる・照れる・眠そうは0.35、その他0.6）。音声の長さだけ8秒単位で繰り返す |
| 待機中の仕草 | `motions/*.json`（`idle-gesture`） | 待機が続くと15〜40秒おきに見回す・回る・伸びる・光をこぼす・揺れる |
| 視線 | `idle.ts` | 目の小さな跳び（約1.7秒ごと）と、体の向きを一部打ち消して利用者側へ向く頭 |
| 揺れの追従 | `secondary.ts` | 頭頂・裾・腕先をばねで遅らせ、行き過ぎて戻す。60Hzの固定刻みで計算し、12/24fpsの上限に左右されない |
| 光 | `light.*` track | `energy`・`sparkle`（粒子の弾け）・`swirl`（粒子と核の軌道の速さ）・`core`（核の脈動）。腕先は動いたときだけ光の尾を引く |

動作データの形式と検査は `clips.ts`。key は `[時刻, 値...]`、回転はラジアン、左右の無い `arm_<outer|inner>_<joint>` は右腕で書き左腕へ鏡映する。体の回転は `spin`（鉛直軸の累積角）で書き、2πの倍数で終える。全trackは静止姿勢で始まり静止姿勢で終わる。発話中は1回転を肩越しの振り向き（最大0.35rad）に変える。後ろを向いている間は目を隠す。

`prefers-reduced-motion` では待機の静止姿勢だけを描く（回転・跳ね・仕草・揺れの追従も止まる）。表示中は待機12fps・身振り24fpsを上限とする。口の振幅同期と音声の pause/resume は未実装。

## 動作の試写

設定「表示」のアニメーションタブ（`LightAvatarMotionLab.tsx`、OpenUI view `avatar-motion-lab`）で全動作・変化版・速度・繰り返し・発話の重ね・各層・ボーン表示を試せる。試写はタブが画面に出ている間だけ描画器を作り、その間は会話背景の精霊を一時停止する。設定には何も保存しない。描画器と動作一覧は `load.ts` の共有dynamic importで読み、three.js を設定画面の初期表示に含めない。

Three.js のライセンスを `THREE-LICENSE.txt` に同梱する。

開発用の依存キャッシュは `node_modules/.vite/development`、ブラウザfixtureはfixtureごとの一時ディレクトリに分ける。異なる環境のViteサーバーが同じキャッシュを置換すると、実行中の開発画面が古い依存URLを参照し、動的importが504で失敗してアバターが消える。Three.jsは起動時の依存最適化に含める。描画hostの `data-avatar-state` で読み込み・描画失敗・非表示・非対応を切り分ける。初期化失敗のconsole警告にはエラーの種類だけを渡す。

2026-10-09以降は、回答全体からLayaが選んだ5種の感情をmotionへ対応させる。親しみ→agreeing、喜び→joyful、寄り添う→listening、興味→curious、驚き→surprised。発話の頷き・手振りは別のcueとして重ねる。待機の呼吸・瞬き・待機中の仕草は判断の有無にかかわらず継続する。会話の名前横にはmotionではなく同じ感情の絵文字を表示する。通常・低確度・fallback、および旧motionだけの回答には感情アイコンを付けない。判定と保存・取消の現行仕様は [Laya計画](../../../../../../spec/laya-voicevox-avatar-plan.md) の現行仕様節を参照。
